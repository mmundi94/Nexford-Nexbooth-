# Nexbooth

**The Nexford holiday photo booth.** Take festive selfies with the Nexford alpaca, add Santa hats and speech bubbles, pick a frame and a filter, then download the photo and share it with the team.

- Works in any modern browser on a laptop or phone (Chrome, Edge, Safari, Firefox).
- Everything happens in the browser. **No photos are uploaded or stored anywhere.**
- No accounts, no servers, no cost. It runs on free GitHub Pages.

## Put it online with GitHub Pages (about 10 minutes, no coding)

### 1. Create the repository

1. Sign in at [github.com](https://github.com) (create a free account if you don't have one).
2. Click the **+** at the top right, then **New repository**.
3. Name it `nexbooth`.
4. Choose **Public**. (Free GitHub Pages needs a public repository. Your team's photos are never stored there, only the booth itself.)
5. Click **Create repository**.

### 2. Upload the files

1. Unzip `nexbooth.zip` on your computer.
2. On the new repository page, click the link **uploading an existing file**.
3. Open the unzipped `nexbooth` folder, select **everything inside it** (`index.html`, `README.md`, and the `assets`, `css`, `js`, and `tools` folders), and drag it all into the GitHub page.
   - Important: `index.html` must be at the top level of the repository, not inside another folder.
4. Scroll down and click **Commit changes**.

### 3. Turn on GitHub Pages

1. In the repository, click **Settings** (top menu).
2. In the left menu, click **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to `/ (root)`, then click **Save**.
5. Wait 1 to 2 minutes and refresh the page. Your link appears at the top:
   `https://YOUR-USERNAME.github.io/nexbooth/`

### 4. Share it

Open the link, allow the camera, and try it. Then share the link with the team.

## Troubleshooting

| Problem | Fix |
|---|---|
| The page shows "404" | Make sure `index.html` is at the top level of the repository (not inside a `nexbooth` folder). Wait two more minutes and refresh. |
| "Camera access was blocked" | Click the camera icon in the browser's address bar and choose **Allow**, then reload. |
| "Your camera is busy" | Close Zoom, Teams, or any other app using the camera, then try again. |
| No camera at all | Click **Use a photo instead** and pick a photo from your computer or phone. |
| Fonts look plain | The fun fonts load from Google Fonts. Some office networks block them. The booth still works with standard fonts. |

## Changing things later

- **Speech bubble phrases:** open `js/app.js`, search for `PHRASES`, and edit the list of messages.
- **Frame captions** (for example "Happy Holidays, Team Nexford"): in `js/app.js`, search for the caption text and change it.
- **Alpaca artwork:** every drawing is in `assets/alpacas` and `assets/props` as an SVG file. The booth itself reads them from `js/assets.js`, which is generated by `tools/art/build.py` (Python, only needed if you want to redraw the artwork).

You can edit any file directly on GitHub: open the file, click the pencil icon, make the change, and click **Commit changes**. The live site updates in about a minute.
